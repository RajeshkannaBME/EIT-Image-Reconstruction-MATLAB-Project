# EIT Image Reconstruction (MATLAB)

This repository contains MATLAB scripts for signal separation and image reconstruction using Electrical Impedance Tomography (EIT).

## Workflow
1. Signal exploration
2. FFT analysis
3. PCA signal separation
4. Filtering
5. Image reconstruction
6. Image validation
7. Automated batch analysis

## Tools
- MATLAB
- Signal processing
- Biomedical image reconstruction

## Repository Structure

src/ → MATLAB scripts  
results/ → summary output data  
images/ → example reconstructed images  

## Note
This repository contains a cleaned portfolio version without restricted datasets.
